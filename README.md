# ReuST - Structural Steel Reuse Framework

A decision-making framework for evaluating efficient end-of-life scenarios of structural steel elements.

Based on the Python code written by [Mussie Birhane](https://github.com/MussieBirhane). See the [original framework](https://github.com/MussieBirhane/decision-making-framework) for more information.

---

## 🚀 Two Versions Available

### 📱 **Modern React App** (Recommended)
Location: `/app/` directory

**Tech Stack**: React 18 + TypeScript + Vite + Tailwind CSS + TensorFlow.js

**Features**:
- ✨ Modern, responsive UI with dark/light themes
- 🎨 Clean Tailwind CSS design
- 🔒 Type-safe with strict TypeScript
- ⚡ Fast Vite build system
- 📦 Feature-based architecture
- 🧪 Full test coverage ready
- ♿ WCAG 2.1 AA accessible

**Getting Started**:
```bash
cd app/
npm install
cd frontend && npm install
cd ../backend && npm install
cd ..
npm run dev  # Visit http://localhost:3000
```

See [`/app/README.md`](./app/README.md) for complete documentation.

---

### 🕰️ **Legacy Version** (Original)
Location: Root directory (`index.html`, `sketch.js`, `style.css`)

**Tech Stack**: p5.js + vanilla JavaScript + TensorFlow.js

**Currently deployed**: [https://reust-ai.github.io/](https://reust-ai.github.io/)

This is the original implementation and remains functional for backward compatibility.

## 🔄 Migration Path

The modern React app (`/app/`) is a complete refactor with all original functionality plus improvements. Both versions are maintained for compatibility, but new features will be added to the React app only.

**Why migrate?**
- Better performance and user experience
- Modern development workflow
- Type safety and maintainability
- Dark/light theme support
- Mobile-responsive design
- Extensible architecture
